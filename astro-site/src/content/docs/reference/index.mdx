Use the API reference to check function signatures, tensor layouts, parameters,
and working-memory requirements. The reference is generated from the heliaCORE
headers and includes public kernels, wrappers, buffer-size queries, and support
helpers. For a direct integration, start with a public kernel or wrapper and
follow its documented constraints.

duplicating declarations across the grouped operator view and the complete
