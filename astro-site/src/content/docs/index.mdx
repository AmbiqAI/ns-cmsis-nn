**heliaCORE** is Ambiq's optimized neural-network kernel library for Ambiq
silicon. This repository delivers it as `ns-cmsis-nn`: a CMSIS-NN-based kernel
layer with Ambiq-tuned operators, CMSIS-Pack delivery, and HELIA integration
paths for Apollo-class Cortex-M accelerators.

This site is a scaffold. The published documentation is the Sphinx site at
[ambiqai.github.io/ns-cmsis-nn](https://ambiqai.github.io/ns-cmsis-nn/) until
the cut-over; see AmbiqAI/ns-cmsis-nn#521.
